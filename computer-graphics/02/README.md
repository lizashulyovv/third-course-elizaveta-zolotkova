 Чем идея Брезенхэма отличается от ЦДА?
 Идея Брезенхэма накапливает ошибку и по ней выбирать следующий пиксель. А ЦДА прибавляет вещественные приращения координат и использует округления.
 
Для чего используется переменная error?
Переменная error хранит накопленную ошибку и помогает определить, нужно ли изменять координаты

Зачем нужны sx и sy?
dx и dy — длины изменения координат без знака.sx показывает, куда двигаться по x:
+1 вправо и -1 — влево. sy делает то же самое для y.

Почему две проверки нельзя бездумно заменить на if ... else?
На некоторых шагах меняется только x, на некоторых только y, а иногда меняются обе координаты.
Если мы применим if ... else, то мы не сможем учитывать изменения на разных координатах.

На каких входных данных проверялась программа?
Программа проверялась на горизонтальном, вертикальном отрезках, справа налево, снизу вверх, крутой наклон и одна точка.

Совпали ли наборы пикселей ЦДА и Брезенхэма во всех примерах?
Не совпали, на примере: (0;0) (4;2) - отличающиеся коодринаты: ЦДА: (1, 1); (3, 2) Брезенхэм: (1, 0); (3, 1)
