как используется симметрия окружности?
Мы можем взять одну восьмую окружности, а остальные точки будут ей симметричны. Если одна точка будет известна, то и остальные также будут известны

почему достаточно строить одну восьмую?
Из-за симметрии нам достаточно вычислять точки только для ондной восьмой, а остальные точки будут симметричны

что означает переменная d?
Эта переменная определяет нужно ли уменьшать y. К примеру, если d < 0, то у остается таким же, а если d >= 0 у уменьшаем

когда уменьшается y?
у уменьшается при выборе SE и d >= 0

почему цикл заканчивается при x > y?
Цикл выполняется пока x <= y, то есть на границе этого сектора x=y, а когда x > y, то следующие очки являются отражением и продолжать вычисления нет смысла

совпали ли пиксели алгоритма средней точки и способа через формулу?
Не во всех случаях совпадают пиксели, к примеру, при радиусе 4 (20,15) 

что показал небольшой эксперимент по времени?
Для сравнения я использовала координаты x=10, y=10, радиусы: 3,5,7,8,9. Эксперимент показал, что алгоритм по формуле показал меньшее время выполненичя. К примеру, при x=10, y=10, радиус = 9 - cреднее время алгоритма по формуле: 0.000140 мс, а среднее время алгоритма средней точки: 0.000200 мс
