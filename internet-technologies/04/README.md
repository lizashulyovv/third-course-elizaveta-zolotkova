1. как запустить проект

Нужно открыть файл index.html. Откроется браузер и страница нашего проекта.

2.какой API используется

Мы используем учебный API - JSONPlaceholder

3.какие HTTP-методы реализованы

Реализованы такие методы, как GET, POST, PATCH, DELETE

4.как устроено состояние приложения

Состояние приложения хранится в state. В нем находится массив публикаций, показатели, которые показывают загружается ли публикация и выполняется ли сохранение, сообщение об ошибке и дает понять создает ли пользователь новую публикацию или редактирует старую

5. как обрабатываются ошибки

В коде используется try, catch и finally.
try - выполняет запрос 
catch - если есть, то видит ошибку и записывает ее
finally - завершает загрузку или сохранение

6.что происходит после успешного POST, PATCH и DELETE

После успешного POST сервер возвращает созданный объект и  код ответа 201. Мы получаем ее и добавляем в начало массива.

После успешного PATCH у нас обновляются данные в публикации

После успешного DELETE мы удаляем публикацю из массива и она исчезает со страницы

7. почему изменения исчезают после полной перезагрузки страницы

Потому что мы используем учебный API, который не сохраняет наши изменения. И после обновления страницы все сбрасывается и загружаются исходные публикации
