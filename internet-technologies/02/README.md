Где хранятся исходные данные?
Исходные данные хранятся в массиве numbers

Почему показатели лучше вычислять из массива, а не хранить отдельно?
Показатели лучше вычислять из массива, потому что при изменении массива они пересчитываются. Если хранить их отдельно, можно забыть обновить один из показателей, и данные станут неправильными.

Что возвращает getStatistics()?
Функция getStatistics() возвращает объект с  показателями массива: количеством элементов, суммой, средним значением, минимальным и максимальным значением.

Как программа обрабатывает пустой массив?
Если массив пустой, программа не выводит случайные значения или Infinity. Для минимального, максимального и среднего значения выводится —, а количество и сумма равны 0.

Какое место в программе было сложнее всего отладить?
Сложнее всего было проверить правильность функции getStatistics() и обновление данных после изменения массива.
