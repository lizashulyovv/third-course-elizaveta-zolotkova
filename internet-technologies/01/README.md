Где в программе хранится состояние?
Состояние программы хранится в переменной value

Какая функция обновляет интерфейс?
Функция render

Какие события обрабатываются?
События обрабатываются такие, как пользователь нажимает на кнопки +1 и -1, сброс

Что произойдёт, если изменить значение переменной, но не вызвать функцию обновления интерфейса?
Само значение переменной изменится, но отображаться будет также старое значение
