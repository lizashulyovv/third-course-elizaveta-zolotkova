какой endpoint используется?
Используется учебный API JSONPlaceholder - https://jsonplaceholder.typicode.com/users

какой HTTP-метод отправляется?
Метод GET

где в программе хранится состояние?
Состояние хранится в константе state

какие состояния интерфейса предусмотрены?
Предусмотрены такие состояния интерфейса, как данные пользователя, загрузка, ошибка, фильтрация

как обрабатывается ошибка?
Ошибка обрабатывается через try...catch, а сообзение сохраняется в state.error

какие поля участвуют в фильтрации?
Участвуют такие поля, как name, username, email

что вы увидели в Network при успешном запросе и при ошибке.
При успешном запросе я увидела статус 200, а при ошибке 404
